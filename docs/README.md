## 使用顺序

1. 从追溯工作簿查找 `REQ`、`DEV`、`TC` 和当前状态。
2. 阅读设计中的对应规则及开发计划中的阶段背景。
3. 按 [Codex 开发指南](agent.md) 修改代码和测试。
4. 将本次验证命令、结果及限制写回用例证据；必要时补充验收记录。

工作簿中的“已验证”只代表所列证据和环境。首版 DMG 的本机验收不等于已完成公开分发的签名、公证及其他目标 Mac 验收。
